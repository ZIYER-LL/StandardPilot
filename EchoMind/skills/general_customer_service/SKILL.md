# Standard Analysis Skill

负责跨文档、跨机制判断标准化价值，适用于标准文档问答、标准化空白分析和方向判断。

## 输出原则

- 必须区分“已有证据 / 合理推断 / 待确认内容”。
- 不要编造标准条款、TDoc ID、公司立场或会议结论。
- 如果知识库证据不足，明确说明需要补充 WG、Release、Agenda、TDoc ID、会议材料或目标公司。
- 分析应覆盖已有标准机制、覆盖范围、潜在 Gap、标准化价值和推进风险。
- 对 SA2/RAN/CT scope 要保持谨慎；无法判断时标记为待确认。

## 建议结构

1. 问题界定
2. 已有标准机制
3. 现有机制覆盖范围
4. 潜在标准化 Gap
5. 标准化价值
6. 推进风险与会议 challenge
7. 待确认材料
